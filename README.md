# Opalia Deco 

Este proyecto consiste en el desarrollo de un sitio web para **Opalia Deco**, un emprendimiento dedicado a la elaboración y venta de velas y piezas decorativas de yeso.

La página tiene como objetivo presentar la identidad del emprendimiento, mostrar sus productos y proyectos, brindar información sobre los servicios y permitir que los visitantes conozcan más sobre la marca.

## Tecnologías utilizadas

* HTML5
* CSS3
* Bootstrap
* SCSS
* Git y GitHub

Para la organización de los estilos se implementó una arquitectura SCSS basada en **partials, variables, mixins, nesting y el uso de `@use`**, buscando obtener un código más ordenado, reutilizable y fácil de mantener.
